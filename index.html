INSTALL BLAKE-TO-SHA

Add BLAKE-TO-SHA to your device for quick access without opening the browser each time.

iPhone / iPad

Safari does not display a standard install prompt. Use the Share menu.

  1. Open BLAKE-TO-SHA in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.

Android

Chrome can install BLAKE-TO-SHA directly as an app.

  1. Open BLAKE-TO-SHA in Chrome.
  2. Tap the browser menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm the installation.

Desktop
